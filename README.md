Рабочая папка по маркетингу сайта https://expertfixservices.com

**База: Карлоу (R93AD98), рабочий радиус 150 км.** Не Дублин — это выяснилось 06.09.2026
и отменило всю первоначальную гео-часть. Дублин попадает в радиус (~85 км), но как один
из городов зоны, а не как база.

Бюджет на рекламу: **€150–300/мес заявлено владельцем, но реклама не запускается**, пока
нет фото по приоритетным услугам и минимум трёх отзывов. Пока — аналитика и бесплатные
каналы.

**Ограничение, определяющее всю тактику:** звонки как канал не используем — только WhatsApp
`+353 89 983 1680` и заявки с формы. Подробно: `local/whatsapp-first.md`.

## Источник правды

`FACTS.md` — единственный. Если факта нет там, публиковать его нельзя: ни на сайте, ни
в Картах, ни в рекламе, ни в переписке. Там же список прямых запретов — «insured»,
годы опыта, выдуманные отзывы, «our team».

Что из этого следует практически: **страховки нет, CRO/VAT нет, отзывов нет, год старта
2025, исполнитель один.**

## Что сделано

**Сайт** переписан с нуля и вычищен от 197 ложных заявлений. Гео — Карлоу, цены — из
`FACTS.md`. Десять страниц, включая четыре городские (`/plastering-carlow`,
`/handyman-carlow`, `/bathroom-renovation-kilkenny`, `/handyman-portlaoise`), FAQ с разметкой,
галерея из 9 гео-нейтральных фото. Три спорные цены стоят как «priced per job» — формулировка
истинна при любом ответе владельца.

**Выложен** на временный адрес `darkorchid-squid-933800.hostingersite.com`. Домен не тронут,
живой сайт остаётся откатом. Выкладка — `npm run release && npm run deploy`: сборка отказывается
работать с незакоммиченными правками, выкладка не подменяет папку при недоборе файлов, старая
версия остаётся, команда отката печатается.

**Форма** больше не врёт. Она показывала «Sent» и отправляла в аналитику конверсию на письмо,
которого не было: эндпоинт не выкладывался, а клиент считал успехом любой ответ 200. Теперь
успех — только распознанный JSON, PHP-эндпоинт едет со сборкой, конфиг с паролем лежит вне
корня сайта (иначе выкладка стирала бы его), и после каждого деплоя проверяется, что
`GET /api/contact` отвечает 405.

**Профиль в Картах** проверен 12.09: метка подтверждена, дубликатов нет, ложных заявлений в
описании нет. Кнопка «Сайт» и чат вели на мёртвый номер — исправлено.

**Аналитика** написана и спит до появления `VITE_GTM_ID`. Политика конфиденциальности читает
тот же переключатель, так что не сможет соврать при включении.
