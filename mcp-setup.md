# MCP — что я реально смогу делать сам

Чтобы не было ложных ожиданий: «всё сделаю через MCP» верно частично. Ниже честная граница.

## Уже работает

| Возможность | Как |
|---|---|
| Аудит сайта, рендер SPA, мобильная версия, скорость, проверка что аналитика встала | Playwright MCP (использован для этого аудита) |
| Все тексты, ключи, объявления, инструкции, отчёты | без MCP |

## Настроим на следующем шаге (read-only, легко)

**Google Analytics 4 + Search Console.** Официальный `analytics-mcp` от Google, доступ по OAuth.
Что мне нужно от вас: добавить мой email (`nikita.dyachkov@casafari.com`) как **Viewer** в GA4 property и в Search Console property. Дальше я подключаю MCP и сам смотрю трафик/конверсии → недельные отчёты по `reports/weekly-template.md`.

Установка (сделаю сам, когда дадите доступ):
```bash
claude mcp add analytics -- pipx run google-analytics-mcp
```

## Позже, вместе с бюджетом на рекламу

**Google Ads.**
- Официальный `googleads/google-ads-mcp` (апрель 2026) — **только чтение**: я вижу кампании, расходы, search terms, могу анализировать и говорить, что менять. Создавать/менять — нет.
- Полноценное управление (создание кампаний, ставки, негативы) — через сторонние write-MCP (Ryze, Scalekit, Adspirer). Требуется **Google Ads developer token** (заявка на Basic Access, 1–5 рабочих дней) + **Manager (MCC) аккаунт**. Заводить это ради €10/мес смысла нет; ради €150–300/мес — да.

**Meta Ads.** Только community MCP + Business-токен с правами `ads_management`. Надёжность ниже, ставим последним.

## Чего я не смогу никогда

- Создать за вас аккаунты Google/Meta (нужен ваш телефон, подтверждение личности)
- Пройти верификацию Google Business Profile (видео с вашими инструментами и адресом)
- Привязать карту и подтвердить платёж
- Вставить код в Hostinger Horizons (нет API/MCP у платформы — только ваш клик)
- Снять фото ваших работ — а это, честно говоря, влияет на результат больше, чем вся техническая настройка

## Итого разделение

**Вы (~2–3 часа один раз):** создать 5 аккаунтов, вставить один блок кода, снять 20 фото работ, пройти верификацию GBP.
**Я (постоянно):** аудиты, все тексты и ключи, аналитика и отчёты, ведение рекламы после подключения write-MCP.
